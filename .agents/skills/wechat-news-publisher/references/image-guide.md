# 图片及独立封面制作规范

## 封面

- 默认微信公众号横向比例 **2.35:1**；推荐 **1175×500** 像素，也可输出同等比例的更高分辨率。
- **禁止标题文字、字幕、Logo 以外的新增字体说明、栏目抬头、日期、价格大字。** 品牌原始标志是产品/品牌视觉本身时可保留，但不要为了装饰再写字。
- 先搜正式新闻稿、企业官网、产品图、活动摄影、开发者视频画面或用户明确提供的实际图片；**确认主体与事件的对应关系**。
- 优先：真实产品或场景图片 → 正确裁切与构图 → 轻度调整对比度与背景 → 导出。
- 不能将合成的“某 CEO 接受采访”“某产品在街上行驶”等虚构现场当作真实照片；用户曾明确否定不符合真实事件的封面。
- 人物封面应使用用户提供或来源可靠的真实照片；不使用看起来相似的另一个人替代，也不改变人物关键外观。
- 图片无法验证来源、授权或具体细节时，不要强行生成“看起来像真的”的场景。可以提供无文字、真实元素构成的非纪实视觉，但要避免误导。
- 独立输出文件示例：`assets/01_example_cover.jpg`。不能在文章 Markdown 中引用该封面，也不要写封面说明段落。

## 正文配图

- 选用官方产品图、应用截图、经过核实的演示帧、示意图或可信的报道插图。
- 每张图都应有功能：读者看图能理解一个产品、研究流程、体验或数据。
- 相关图片放在对应的小节，而不是聚集在开头；依据内容适当控制数量。
- 素材与配图需满足版权和发布使用条件，不能假定网上可见就可商业转载。必要的署名可用简短图注，不把全篇来源清单搬进结尾。
- Markdown 示例：

  `![官方演示的产品界面](assets/01_example_screen.jpg)`

  图注可写 `*图：官方产品发布资料。*`，避免长串参考链接。

## 图片校验

- 图片本身确实存在，尺寸符合用途，主体未被裁断。
- 公众号封面无文字且比例正确。
- 正文配图在 Markdown 相对路径下可以打开。
- 素材说明与事实一致（演示截图不能当作已上市设备照片）。
- 不能生成图片或无法取得素材时，应明确说明哪些文件没有完成，不得虚报。

## 封面与正文必须区别（新增强制检查）

- **封面与正文配图必须使用不同的视觉信息，绝不允许同一源图仅换裁剪比例、尺寸、颜色或背景后重复出现。** 文件 SHA 不同不足以证明图片不同，须同时检查内容与实际来源。
- 优先从不同的真实、可信且可合法使用的原始素材中分别选图；封面展示事件整体，正文图展示支持具体段落的真实信息，例如发布截图、技术示意、财报图表、文件截图、产品细节等。
- 如果只有一张获得合适使用许可的事件相关照片，可以将其用于独立封面；正文应另行制作**基于已核实数据、明确标注口径与不确定性的原创信息图**（SVG/PNG/JPG 均可），而不是把照片再裁切一次。原创信息图不应冒充新闻实拍，图注应写明是“根据公开报道整理的说明图/数据图”，数据必须可追溯。
- 若正文配图与封面高度相似，必须把该篇标记为“图片重复、图文未完成”，主动更换，不能仅修改文件名或重复使用原图。
- 检查 README 的图片来源记录：分别写出 `cover_source` 与 `body_source`，并确认正文引用的图片文件真实存在且可正常显示；过时的重复图片引用应移除，废弃图不要继续当成正文资产使用。
- 除非用户另有说明，**独立封面依然无新增标题/文字**；上述要求仅限制正文/封面的不同，不禁止正文信息图使用准确标注。
