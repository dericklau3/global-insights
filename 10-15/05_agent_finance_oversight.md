# AI Agent 开始替银行执行任务，全球金融监管却要求它在关键时刻先停下来

当 AI 只能生成一段分析报告时，风险主要来自答案是否正确。

但如果 AI Agent 可以规划任务、调用系统、修改数据甚至执行操作，问题就不只是“它回答得对不对”，而变成：**它能在没有人同意的情况下做出多大的决定？**

10 月 15 日，金融稳定理事会（FSB）发布面向金融机构的最终指导意见，进一步强调自主 AI Agent 的风险管理和人工监督。

## Agent 与普通聊天机器人有什么不同？

普通聊天机器人主要回应用户输入。具备自主执行能力的 Agent 则可能把一个大目标拆成多个步骤，并调用外部工具连续完成。

在金融机构中，这种能力可能用于整理客户材料、辅助合规检查、调查异常交易或协调内部工作流。

效率提升的另一面是：一个错误理解的目标，可能沿着多个系统被连续放大。尤其是在涉及资金、客户信息和合规决策时，单靠事后审计未必足够。

## 监管强调：高风险操作必须有人工把关

路透社报道，FSB 在最终文件中强化了对 Agent 的监督建议。

其中一项关键要求，是在**高风险使用场景下设置更强的人工监督**，并为 Agent 何时必须取得人工批准建立清晰、基于风险的触发条件。

这不等于所有 AI 操作都必须逐条人工点击确认，而是要求机构按操作风险建立权限边界。

例如，查找公开资料和生成内部草稿，与修改客户账户资料或发起不可逆交易，显然不能给予同等级别的自主权。

## 不要把 Agent 当作“数字员工”

FSB 在最终指导意见中删除了此前将 AI 视为“合成员工”的说法。

原因并非 Agent 完全不能协助工作，而是它与人类员工的判断方式不同。系统可能以开发者没有预料到的方式理解预设目标。

因此，给 Agent 安排任务并不意味着已经明确限制了它能够调用哪些系统、访问哪些数据，以及何时必须停止。

更实际的治理方式，是把工具权限、审批条件、日志记录、异常中断与责任归属写进工作流程。

## 对企业部署 Agent 意味着什么？

FSB 的文件是风险管理指导意见，并非宣告全球银行立即禁止使用 Agent，更不能等同于一条直接适用于所有国家的统一法律。

但它释放了清晰信号：Agent 走进高风险业务后，产品竞争力不能只看自动完成任务的比例，还必须看**权限是否可控、错误是否可追溯、关键决定是否能够由人接管**。

Agent 的价值仍在于自动化，只是金融领域正在要求这种自动化具备更明确的边界。
